# 审阅

确认本轮要判断的问题、观看尺度、已认可参考与源资产。沿用[工作约定](../machine-design/shared/references/workflow.md)中的自主偏好；单独审阅不隐含修复授权。审阅主责是判断视觉和运动效果；场景结构及依赖事实由[场景盘点](../machine-inspect/SKILL.md)提供。

选择足以揭示问题的视图：整体前后斜视判断轮廓，正交视图判断对齐，局部近景判断连接、厚度与接缝。内部检查通过临时显隐或局部视图，并保留周边参照。不要仅以一个好看的角度验收。

素模区分形态和法线问题；贴图视图检查边语义、方向、像素尺度和原图保护。同机位/光照对比，避免材质感觉被不同展示条件混淆。常规显隐与视角直接使用 Blender；[审阅视图工具](references/views.md)可生成取景方向并在交互 Blender 设置/恢复视口，不创建永久相机或删除几何。

运动同时看关键姿态与连续动作，必要时反向、复位和随机跳转。薄缝看正/斜向，实例和修改器看求值结果。连续观察、离散碰撞采样和连续扫掠证明是不同证据。

先解释具体观察，再给判断。能量化的问题交给[几何检查](../machine-geometry-check/SKILL.md)或[UV 检查](../machine-uv-check/SKILL.md)，指标不能代替视觉判断。发现问题后按类型由建模、模型修饰、贴图或动画主导修复；已有修复授权时可连续完成必要修改，无需机械交接。结果简洁说明问题位置、影响、建议和覆盖盲区；没有值得长期保留的新信息就不生成报告文档。
