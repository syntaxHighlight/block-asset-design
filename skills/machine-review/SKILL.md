# 审阅

确认本轮要判断的问题、观看尺度、已认可参考与源资产。沿用[工作约定](../machine-design/shared/references/workflow.md)中的自主偏好；单独审阅不隐含修复授权。本技能判断视觉和运动效果，场景结构及依赖事实由[场景盘点](../machine-inspect/SKILL.md)提供。

先按本轮要求辨认各功能组承担的作用，再检查组内及组间关系：部件方向是否配合、连接位置是否成立、比例是否支持功能辨识、支承与接触是否符合设计。把组合后的功能组作为判断对象；单个零件完整、无破面，不足以证明组合合理。设计中有意的简化按已认可要求判断，不自行补成工程仿真。

按关键要求、改动部位及其关联关系选择视图：用整体前后斜视判断轮廓，正交视图判断方向、比例与对齐，局部近景判断连接、厚度与接缝。通过临时显隐或局部视图检查内部，并保留周边参照。指出重要部位是否被遮挡或尚未观察；单个好看的角度不足以支持验收。

观察素模时区分形态和法线问题；在贴图视图中检查结构边语义、方向、像素尺度和原图保护。按需使用棋盘格辨别映射拉伸，再用真实贴图核对显示效果。在相同机位和光照下对比，避免展示条件差异干扰对材质效果的判断。

常规显隐与视角直接使用 Blender；[审阅视图工具](references/views.md)可生成取景方向，并在交互 Blender 中设置和恢复视口，不创建永久相机或删除几何。

需要为用户交付反复查看和接管的控制入口时，交给[审阅面板](../machine-review-panel/SKILL.md)制作。面板是否运行不影响本技能独立审阅，控件可用也不代表资产质量已通过。

检查运动时，同时观察关键姿态与连续动作，必要时反向播放、复位和跳转抽查。正对接缝，并从斜向观察薄缝；实例及带修改器的对象，应检查求值后的几何。连续观察、离散碰撞采样和连续扫掠证明分别提供不同的证据。

先解释具体观察，再给判断。能量化的问题交给[几何检查](../machine-geometry-check/SKILL.md)或[UV 检查](../machine-uv-check/SKILL.md)，指标不能代替视觉判断。将候选问题判断为有意设计或可接受例外时，说明适用部位与观察依据；抽查结论只覆盖有依据的同类情况。

发现问题后，按类型交给建模、模型修饰、贴图或动画修复；已有修复授权时，可连续完成必要修改，无需逐项交接。由制作或迭代流程调用时，将发现和观察依据返回原流程继续处理。

简要说明问题位置、影响、建议、关键要求的观察结果和覆盖盲区；没有值得长期保留的新信息时，无需生成报告文档。
