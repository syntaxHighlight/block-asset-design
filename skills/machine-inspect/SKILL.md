# 场景盘点

按[工作约定](../machine-design/shared/references/workflow.md)确定目标资产和盘点范围。已有记录与当前资产一致，且足以回答问题时，直接复用，只补充缺失信息。

1. 按[工具说明](../machine-design/shared/references/tools.md)运行 `blender_audit.py --mode inventory`，显式指定对象或集合及项目内的报告路径。报告只代表选定范围，结论也限定在该范围内。
2. 查清对象与父子关系、材质及图片、UV 层、修改器、约束和驱动器。现有工具提供基础字段；任务需要的材质节点连接、集合关系等信息可通过只读查询补充，未读取的内容保持未知。
3. 区分已确认的依赖、缺失引用候选和无法核实的项。空约束目标不一定是故障；按需补查脚本引用、嵌套节点组以及工具无法判断的图片类型。不得运行未知脚本来证明依赖完整。
4. 简要说明场景结构、依赖问题、未核实项和建议的下一步。仅在涉及具体质量问题时，进入相关的[审阅](../machine-review/SKILL.md)、[几何检查](../machine-geometry-check/SKILL.md)或[UV 检查](../machine-uv-check/SKILL.md)。

盘点只提供事实。若用户还要求继续制作，再按[接手规则](../machine-design/shared/references/takeover.md)确定以哪个文件为准、哪些部分必须保留及如何修改。修复交给对应制作技能处理，沿用已有授权；单独盘点不修改资产。

完成条件：当前问题所需的场景与依赖信息已明确，范围和未核实项已说明。仅在复用或复现需要时保留详细报告。
