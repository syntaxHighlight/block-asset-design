# 动画

读[工作约定](../machine-design/shared/references/workflow.md)。沿用建模或已有资产中的控制器和机构，避免另建一套临时动画再重做。允许为最终动作重构约束；先查清控制参数、父子关系、驱动器及脚本引用，信息不足时用[场景盘点](../machine-inspect/SKILL.md)。需要选型时用[能力查询](../blender-capabilities/SKILL.md)。若任务转为重新设计主体布局或功能构件，由[建模](../machine-model/SKILL.md)主导；运动所需的局部几何调整按相关规则完成。

1. 先确认运动职责、轴心、起止和中间姿态、设计允许的接触与交接；再调整速度、停顿和循环。运动合理性与演示节奏分别判断，简化动作不宣称工程仿真。
2. 预览播放器使用模型现有的控制器和机构，不另建一套运动逻辑。验证任意姿态起播、前后跳转、复位和循环无状态漂移；姿态求值不能依赖上一帧累积状态。伸缩件以固定的基准长度或参考态几何计算变形，几何变化同时检查 UV 密度。
3. 机构重构后检查丢失目标、驱动器、对象引用、交接位置和受影响组合动作。将装饰性静态部件与必需运动分开，不为每个紧固件增加动画。
4. 按[审阅](../machine-review/SKILL.md)观察连续动作、关键交接及遮挡；必要时读求值几何进行碰撞检查。普通 Limit 约束不能替代几何净空检查；需单独说明刀具的预期接触，以及刚性部件之间允许的固定接合。
5. 保留可编辑机构；仅目标导出确有需要时烘焙派生动画。导出变形需检查拓扑稳定，求值网格编号不保证跨帧一致。

完成条件：预期动作、交接、节奏与循环可观察，随机跳转无状态漂移；明确采样覆盖与未验证的连续扫掠范围。截图或有限姿态通过不代表连续无碰撞。
