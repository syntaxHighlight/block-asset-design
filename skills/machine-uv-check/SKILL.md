# UV 检查

按[工具说明](../machine-design/shared/references/tools.md)运行 `blender_audit.py --mode uv`。显式选择 UV 层和同一图集域的对象，并提供真实图像宽高；多图集分开检查。源展开与材质采样层分别核查，不假定活动层就是生产层。

重叠使用面三角化后的正面积交叠，边接触不算重叠；同一面内部的三角形也需检查，但共享边不算重叠。有意共享记录用途，不自动拆岛。工具不自动理解材质节点中的 UV 变换、UDIM 或图集子图范围，这些需额外核验。

越界检查每个面角的 UV 坐标；Minecraft 最终 UV 无循环豁免。像素对齐检查 `u*width`、`v*height` 是否接近整数角点；纹理采样中心是另一约定，不能混用。

密度与拉伸基于三角形在模型表面的二维基与像素 UV 的线性映射，报告两个奇异值及其比值。提供目标密度才作密度偏差判断；面积比不能独自证明无各向异性拉伸。具体容差按用途选择，不统一强制所有表面。

检查结果提供数据证据，结合[审阅](../machine-review/SKILL.md)中的棋盘格和真实贴图判断。模型空间形态优先于 UV 顶点取整。工具范围、候选截断、未读到 UV 的对象都必须保留在结论中。UV 修复由[贴图](../machine-texture/SKILL.md)主导；已有修复授权时可连续处理，单独检查时不修改资产。
