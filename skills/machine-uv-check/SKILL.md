# UV 检查

按[工具说明](../machine-design/shared/references/tools.md)运行 `blender_audit.py --mode uv`。根据实际材质采样使用的 UV 层、图像尺寸和图集关系划分检查范围，显式选择 UV 层与对象，并提供真实图像宽高；多个图集分开检查。

同一对象的不同面使用不同图像时，分别核验对应表面，不能对整个对象套用同一图像尺寸。工具调用未覆盖的材质采样关系需另行核验。

分别核查[源展开与生产 UV](../machine-design/shared/references/glossary.md)，确认实际使用的生产 UV，不能仅依据活动层判断。检查需覆盖本轮涉及的主要表面与材质；局部结果只支持对应范围的结论。

将面三角化后，按三角形之间是否存在正面积交叠判断重叠，同一面内的三角形也纳入检查；仅边接触不算重叠。有意共享的部分需记录用途，不自动拆岛。材质节点中的 UV 变换、UDIM 或图集子图范围需额外核验，工具不会自动识别这些关系。

越界检查每个面角的 UV 坐标；Minecraft 最终 UV 不因纹理可重复平铺而豁免越界检查。像素对齐检查 `u*width`、`v*height` 是否接近整数角点；纹理采样中心是另一约定，不能混用。

根据三角形表面二维坐标到 UV 像素坐标的线性映射计算密度与拉伸，报告两个奇异值及其比值。只有提供目标密度时，才判断密度偏差；仅凭面积比不能证明没有各向异性拉伸。具体容差按用途选择，不对所有表面强制使用同一容差。

结合检查数据与[审阅](../machine-review/SKILL.md)中的棋盘格和真实贴图作出判断。模型空间形态优先于 UV 顶点取整。结论需说明检查范围、未读到 UV 的对象和未完成的检查。

达到计算预算造成的未完成检查不能视为通过；仅省略部分定位样例时，仍可依据完整检查的总数判断，并说明展示范围。

UV 修复交给[贴图](../machine-texture/SKILL.md)处理；已有修复授权时可连续处理，单独检查时不修改资产。
