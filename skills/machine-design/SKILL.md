# 机器资产制作

读取[工作约定](shared/references/workflow.md)，明确用户目标、当前资产和已认可要求。综合任务按下表选择负责的技能；明确的单项任务直接进入对应技能，无需经过本入口。接手既有模型时，按[接手规则](shared/references/takeover.md)补齐本轮必要信息。

制作 Minecraft 资产时加载[Minecraft 制作规则](shared/references/profiles/minecraft.md)；用户要求 Immersive Engineering（IE）风格时，再读[风格方向](shared/references/profiles/ie-style.md)。

## 选择入口

| 当前需要 | 读取并执行 |
| --- | --- |
| 关键设计选择尚不明确 | [需求澄清](../machine-brief/SKILL.md) |
| 新建或改变比例、布局、功能构件，验证机构可行性 | [建模](../machine-model/SKILL.md) |
| 改善已确定设计的拓扑、接合、法线与局部轮廓 | [模型修饰](../machine-refine/SKILL.md) |
| 展开 UV、生成程序化贴图与整理图集 | [贴图](../machine-texture/SKILL.md) |
| 完善机构、时序与动作 | [动画](../machine-animate/SKILL.md) |
| 围绕已明确目标继续打磨至达标 | [局部迭代](../machine-iterate/SKILL.md) |
| 制作便于查看和接管的侧栏控制面板 | [审阅面板](../machine-review-panel/SKILL.md) |

新建任务可参考建模、模型修饰、贴图和动画的顺序。选择技能时，以本次要解决的问题为准；已有成品改变比例或布局时仍属于建模。明确各部件当前以哪个可编辑源为准。

需要查找美术素材或既有接口时，按[资源查找与使用](shared/references/resources.md)先复用项目内容；本地资源不足且需要检查指定模组时调用[模组资源提取](../mod-resource-extract/SKILL.md)。

## 制作与收敛

用户确认方案并授权制作后，直接推进，无需再询问是否开始。用户只要求讨论或试样时，保持该范围。结合当前资产确定尚需完成的阶段，复用已有合格部分。

完整制作默认交付可编辑模型和基本材质，有运动需求时包含能说明工作原理的简单动画；终点停止或循环按已确认要求处理。精细贴图、复杂动作和外部导出以已确认范围为准。

先验证比例、功能布局、接口与机构空间，再细化形态和表面；必要时提前用简单运动验证可行性。

每阶段向[局部迭代](../machine-iterate/SKILL.md)提供明确的目标、保护范围与验收条件，由它安排制作和审阅，并自主判断何时完成。按[操作索引](references/operations.md)选择工具。阶段达标后，自动进入下一个必要阶段。

动画若暴露机构行程或外壳空间问题，回到建模修正，再复查受影响的表面和运动；无关阶段无需重跑。只有需要改变共识、扩大授权，或关键问题持续无法解决时，才交给用户决定。

需要反复切换视角、调整显隐或控制动作来查看成果时，调用[审阅面板](../machine-review-panel/SKILL.md)制作适合资产的控制界面；简单模型可沿用原生界面。面板供查看和接手资产使用，自动制作无需等待面板确认，资产仍需实际审阅。

交付前，对最终组合资产执行[整体审阅](../machine-review/SKILL.md)，核对已确认要求、功能组之间的关系，以及各阶段修改对形态、材质和运动的共同影响。确保当前源文件及依赖可继续编辑、约定的动画可播放。各阶段已经通过，最终资产仍需审阅。

发现问题时返回对应阶段修复，并按[局部迭代的完成与暂停条件](../machine-iterate/SKILL.md#自主决定终点)复查受影响项及整体效果。达标后自主结束；有关键未验证项时明确其对验收的限制，按同一规则处理。

完成后提供可编辑文件的位置、查看或播放方式，以及尚未验证的部分；如生成面板，给出手动运行脚本的路径与步骤。只在产生新术语、共识或可复用发现时按[记录规则](shared/references/memory.md)更新已有文档。
