# 操作索引

| 当前问题 | 独立入口 |
| --- | --- |
| 检查指定模组的协议、候选资源及提取依赖 | [模组资源提取](../../mod-resource-extract/SKILL.md) |

| 破面、孔洞、重叠面、空间网格对齐 | [几何检查](../../machine-geometry-check/SKILL.md) |

按本轮目标选择需要的检查，无需默认全部运行。确定性工具及其输入输出见[工具说明](../shared/references/tools.md)。诊断默认只读；使用有写入行为的工具时，明确修改目标和输出位置，并按[来源和恢复约定](../shared/references/workflow.md#来源和恢复)保留必要的可编辑源或可恢复的状态。
