# Immersive Engineering 目录来源与使用边界

本目录仅包含检索元数据和原始许可证。原图、裁切图、动画元数据文件、预览及模型均未随技能携带；目录条目不代表素材已经安装或当前可用。实际提取产物保存在目标项目中。

目录来源为历史归档中的 Immersive Engineering `1.21.1-12.4.2-194` 资源记录。JAR 元数据署名为 **BluSunrize and Damien A.W. Hazard**，这是项目级署名，不代表已逐项确认原作者。资源与美术版权属于各自原作者。

[LICENSE.IE.txt](LICENSE.IE.txt) 原样保留 **Blu's License of Common Sense**，来自上游标签 `12.4.2-194` 对应提交 `583a182549d284a35c813b55ac2a0d1fddcf945a`；固定版本地址和许可证哈希见 [catalog.json](catalog.json)。本说明不替代原文或追加授权。

`catalog.json` 按归档原字节保留稳定 ID、分类、包内路径、SHA-256、裁切矩形及模型映射证据。其 `usage_scope`、证据中的“用户已接受”等表述属于历史项目记录，不能作为当前任务的用途确认，也不能证明图案对应当前模型的电压、能源能力或功能。历史本地使用不构成公共分发授权；当前任务遵循[素材用途与授权确认](../../../shared/references/material-permissions.md)。

[provenance.json](provenance.json) 记录历史 manifest 中的固定 JAR SHA-256 和归档元数据哈希，仅用于来源复核。历史 `manifest.json` 包含当时已安装图片路径，未恢复为本目录清单；原始 NOTICE 的哈希也只作为历史来源记录。

需要实际资源时，使用 [mod-resource-extract](../../../../mod-resource-extract/SKILL.md) 检查指定版本、许可和本次用途。`catalog.json` 是检索目录，不是提取清单；从选定 ID 追到 `sources` 中的包内路径与哈希，检查裁切、模型、材质及动画依赖，再按[版本 1 清单契约](../../../../mod-resource-extract/references/manifest.md)生成项目提取清单，完成用途确认后再执行提取。
