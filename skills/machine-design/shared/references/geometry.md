# 几何与语义契约

功能组、运动组、合并范围、材质分区分别表达。同步演示不证明永远同动；独立显隐、装配和脚本使用也可要求保留对象。

修改拓扑前识别需保留的 UV 层、材质角色、边属性、受保护原图及约束/脚本引用。面、边、环编号仅在当前网格内有效；布尔、减面和重排后必须检查映射，不能照搬旧索引。迁移使用几何、源 UV 和明确语义的交叉依据，不能确定时局部重标。

布尔融合检查操作双方所需 UV 层和属性命名；合并后的默认活动层不一定是实际材质使用层。检查新面的 UV 是否塌缩到原点，导致纹理仅采样该位置。Join 只组织对象，不能自动消除相交内部面或接缝。

结构边角色为 `none`、`form`、`joint`，生成器传输值对应 0、1、2。形体边、装配缝与 UV seam 独立；三角划分、材质变化和岛边界不自动生成描边。边角色写在 Blender EDGE 域整数属性 `md_edge_role`；面材质角色用 FACE 域整数 `md_material_role`，对象 JSON 字符串属性 `md_role_names` 映射整数到配方名称。未设置的区域需要明确映射后才生成。

删除隐藏面要依据所有相关视角与状态中的固定不透明遮挡，不使用活动门、透明玻璃或当前相机判断永久隐藏。结果若为开放渲染网格，后续实体布尔前重新恢复或检查闭合条件。

源网格用于编辑定位，求值网格用于观察修改器与实例后的实际结果。求值索引不保证可直接定位原网格，也不保证跨帧稳定。检查输出必须标明这一区别。
