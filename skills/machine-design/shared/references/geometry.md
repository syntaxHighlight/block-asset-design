# 几何与语义契约

分别标明[功能组、运动组、几何合并范围和材质分区](glossary.md)。演示中同步运动的部件，在其他相关状态下未必保持相对位姿不变；独立显隐、装配和脚本使用也可能要求保留独立对象。

修改拓扑前识别需保留的 UV 层、材质角色、边属性、受保护原图及约束和脚本引用。面、边、环编号仅在当前网格内有效；布尔、减面和重排后必须检查映射，不能照搬旧索引。迁移这些映射时，结合几何特征、源 UV 和已知语义交叉核对；无法确定对应关系时，重新标注受影响区域。

布尔融合前，检查两个操作对象所需的 UV 层及属性名称；合并后的默认活动层不一定是实际材质使用层。检查新面的 UV 是否塌缩到原点，导致纹理仅采样该位置。Join 将多个对象合为一个对象，不能自动消除相交内部面或接缝。

结构边角色为 `none`、`form`、`joint`，传给生成器的值分别为 0、1、2。形体边、装配缝与 UV 切口各自独立；三角划分、材质变化和岛边界不自动生成描边。

边角色写在 Blender EDGE 域整数属性 `md_edge_role`；面材质角色使用 FACE 域整数属性 `md_material_role`，对象 JSON 字符串属性 `md_role_names` 将角色整数映射到配方名称。

面角色以整面为单位；设计上位于单面内部的材质分区，需先明确其几何或贴图表达方式。生成前核对面角色到配方名称的映射；缺少面属性时显式指定默认角色，缺少边属性时不生成结构描边，具体入口见[贴图工具](../../../machine-texture/references/texture-pipeline.md#原生数据与导出)。

删除隐藏面要依据所有相关视角与状态中的固定不透明遮挡。不能因面被活动门或透明玻璃遮挡，或在当前相机中不可见，就判定它永久隐藏。结果若为开放渲染网格，后续执行实体布尔前，须恢复闭合状态或核实是否满足该操作的闭合要求。

使用源网格定位编辑位置，使用求值网格观察修改器与实例后的实际结果。求值索引不保证可直接定位原网格，也不保证跨帧稳定。检查输出必须标明使用的是哪种网格。
