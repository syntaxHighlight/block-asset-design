# 接手已有资产

适用于模型并非由本技能生成、缺少标记或中途由用户/其他工具接管的情况。无需重新走草稿阶段。

1. 复用与当前资产一致的场景记录；信息不足时调用[场景盘点](../../../machine-inspect/SKILL.md)，查明对象、材质、UV、约束、驱动和外部依赖。本规则据此确定制作依据与保护范围，不重复盘点。
2. 从现有共识与资产确认本轮保护范围、观看条件和目标。不知道的信息保持未知；只问会改变本轮选择的事项，不让用户填完整问卷。
3. 当前手工模型默认是制作依据。查清生成脚本覆盖范围后才重生成；不能仅凭文件名推定“最新”或因结构不熟悉而重建。
4. 缺少语义时仅补受影响区域，已有材质、顶点组和自定义属性可作为判断依据，但需核实是否仍然有效。拓扑变更后重新验证映射。
5. 诊断发现的问题按与目标的关系选择处理；报告有影响而无法验证的依赖。局部修改优先，不自动清理旧文件、重命名全部对象或覆盖整个场景。

完成条件：有可操作的资产入口、明确修改与保留范围，能进入需要的阶段。
