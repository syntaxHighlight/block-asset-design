# Immersive Engineering（IE）风格方向

用户要求 IE 或类似低面数工业像素风时读取；这是可调整方向，不是所有机器的硬约束。精确接口遵循目标版本资源契约。

- 正常游戏视距下先读懂轮廓、功能分区与动作。为辨识适度简化或调整比例，随后检查净空。
- 支承、连接、厚度、开口、工作接触要可信；不可见工艺可简化，不要求完整工程仿真。
- 大块连续外皮保持完整，分缝对应真实门、盖板和机构边界。空白不表示缺细节。
- 影响轮廓、遮挡、装配或运动的形状用几何；微小倒角、收边与表面层次优先考虑像素表达。
- 底纹、加工条纹和磨损克制，避免压过轮廓；材质试样与整机都要审阅。
- 配色表达材质和部件职责，强调色留给有含义的局部。不把某台机器的具体配色固化为通用标准。
- 紧固件有真实安装依据，窄条避免多层描边与装饰拥挤。
- 动画强调接触、承托、停顿与交接，不为所有内部步骤添加运动。

通用程序化配方只是自制起点，不声称还原原作者算法或已经匹配具体版本。按当前参考、观看尺度和用户反馈调整。
