# Immersive Engineering（IE）风格方向

用户要求 IE 或类似低面数工业像素风时，读取本文件。这些风格方向可按任务调整，无需作为所有机器的硬约束；精确接口仍遵循目标版本的资源契约。

需要使用 IE 原图或模型时，从[素材目录](../../../references/material-sources.md)查找，并在使用前执行[用途与授权确认](../material-permissions.md)；风格要求本身不代表已确认附属用途。

- 在正常游戏视距下检查轮廓、功能分区与动作是否容易辨认。为提高辨识度，可适度简化或调整比例，随后检查净空。
- 支承、连接、厚度、开口和工作时的接触关系要可信；不可见工艺可简化，不要求完整工程仿真。
- 大块连续外皮保持完整，分缝对应真实门、盖板和机构边界。空白不表示缺细节。
- 影响轮廓、遮挡、装配或运动的形状用几何；微小倒角、收边与表面层次优先考虑像素表达。
- 底纹、加工条纹和磨损克制，避免压过轮廓；材质试样与整机都要审阅。
- 用配色表达材质和部件用途，强调色留给有含义的局部。不把某台机器的具体配色固化为通用标准。
- 紧固件有真实安装依据；窄条上的描边和装饰保持简洁，避免相互挤占空间。
- 动画强调接触、承托、停顿与交接，不为所有内部步骤添加运动。

通用程序化配方可用作自制材质的起点，需按当前参考、观看尺度和用户反馈调整；不能声称其还原了原作者算法或已经匹配具体版本。
