# 少量持久记录

只记录值得下次继续使用的信息：

- 术语：实际出现歧义时定义，用一两句说明含义。
- 共识：已认可要求、重要取舍、必要的来源与保护边界。
- 发现：能减少重复探索的原因、适用条件、有效办法与限制。

优先修订项目已有权威记录；没有上述信息时，无需新增记录。无需为每个资产建文档，也不写逐轮日志或常规检查流水。可直接从模型、工具帮助或配置读取的事实不重复抄写。

新经验先记录在使用者项目中，并注明适用版本、条件和核验结果。项目特有结论留在项目；通用经验经核验并确认需要纳入后，再维护技能源码。普通制作任务不自动改写已安装技能。

仅当取舍长期重要、改变代价较高且缺少理由易被误改时，才写简短 ADR。术语表不记录实现细节。一次性诊断留在反馈中；确有复现用途时才保存详细报告。用户纠正旧共识时，更新原有记录，避免两处相互矛盾。
