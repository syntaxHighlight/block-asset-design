# 机器制作术语

**功能组**：共同承担某个机器功能的部件集合，内部可以相对运动。

**运动组**：所设计运动中相对位姿不变的部件集合，不等同于必须合并的网格。

**几何合并范围**：为形成连续表面或整理几何而选定的合并对象范围。

**材质分区**：采用相同材质用途或表现的表面区域，可跨部件也可在单面内部。

**结构边语义**：表面边的真实结构含义，例如形体收边或装配缝。

**UV 切口**：为展开而断开的边界，不必是实体装配缝。

**源展开**：用于继续调整表面展开关系的 UV。

**生产 UV**：实际连接目标贴图、供最终材质采样的 UV。

**方块网格**：多方块机器占位与接口定位使用的空间网格。

**造型网格**：模型尺寸与顶点位置参考的细分空间网格。

**UV 像素网格**：由目标图像分辨率定义的二维像素格点，与造型网格独立。
