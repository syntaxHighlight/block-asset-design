# 机器设计需求澄清

先读[工作约定](../machine-design/shared/references/workflow.md)，查阅现有资产、参考和共识，自行查证事实。修复目标已明确时，直接处理，无需重新访谈。

按依赖关系梳理待定选择：用途及观看场景 → 占位和接口 → 轮廓与功能可读性 → 运动及空间 → 表面风格 → 本轮验收。跳过已有答案的问题；前置选择尚未确定时，将依赖它的后续问题留到下一轮。

集中提出本轮可以决定的问题，逐项说明推荐方案和取舍；用户可直接同意，或只指出需要更改的项目。文件中可查的事实由助手查阅，无需用户记忆。相关前置问题回答后，即可在用户授权范围内制作试样，无需等待无关问题全部回答；用户只要求讨论时，继续讨论。

制作试样前，先明确它要回答的问题。比例与布局按[建模](../machine-model/SKILL.md)、运动按[动画](../machine-animate/SKILL.md)、材质按[贴图](../machine-texture/SKILL.md)的规则制作。用可审阅的成果辅助决策，再判断是否沿用为正式资产。每轮做到足以帮助决定当前问题即可，其余细节可随后确定。发现限制相互冲突时，讨论整体取舍，避免反复局部修补。

完成条件：当前制作目标、需保留的共识及判断依据已经足够明确。完整制作还需明确可编辑模型、基本材质、是否需要简单动画，以及精细贴图或导出等额外范围。

最终确认时，说明方案、交付范围和验收依据。用户确认方案并授权制作后，直接交给[全流程](../machine-design/SKILL.md)推进，无需再次询问是否开始。单项任务交给对应阶段；只讨论的请求在达成共识后结束。按[记录规则](../machine-design/shared/references/memory.md)更新必要信息，无需另写整套过程报告。
