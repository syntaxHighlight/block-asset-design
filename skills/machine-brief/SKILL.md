# 机器设计需求澄清

先读[工作约定](../machine-design/shared/references/workflow.md)。查现有资产、参考和共识，事实自行查证；明确的修复任务不重新访谈。

将待定选择组织为有依赖的设计问题树：用途及观看场景 → 占位和接口 → 轮廓与功能可读性 → 运动及空间 → 表面风格 → 本轮验收。已有答案跳过，前置选择未定的后续问题留到下一轮。

集中提出本轮可决定的问题，逐项说明推荐方案和取舍，用户可只回答同意或更改项。不要求用户记忆文件可查的事实。相关前置问题回答后，可在用户授权范围内制作试样，无需等待无关问题全部回答；只讨论的请求保持讨论模式。

试样先明确要回答的问题：比例与布局按[建模](../machine-model/SKILL.md)、运动按[动画](../machine-animate/SKILL.md)、材质按[贴图](../machine-texture/SKILL.md)的规则制作。用可审阅成果辅助决策，是否继续作为正式资产另行判断。每轮只推进到下一份有价值的成果，不强求先定下全部细节。识别限制冲突时讨论整体取舍，避免反复局部修补。

完成条件：当前制作目标、需保留的共识及判断依据足够明确。完整制作需明确可编辑模型、基本材质、是否需要简单动画，以及精细贴图或导出等额外范围。最终确认说明方案、交付范围和验收依据；用户确认方案并开始制作后，直接交给[全流程](../machine-design/SKILL.md)推进，无需再次询问是否开始。单项任务交对应阶段，只讨论的请求到共识结束。按[记录规则](../machine-design/shared/references/memory.md)更新必要信息，不新增整套过程报告。
