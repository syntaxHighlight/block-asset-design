# 资产审阅面板

为当前资产制作便于查看和接手的面板，沿用[工作约定](../machine-design/shared/references/workflow.md)确定目标项目、源资产和授权范围。面板帮助用户操作，视觉与运动效果仍由[审阅](../machine-review/SKILL.md)判断。自主制作和迭代可继续进行，无需等待用户操作面板才能验收。

## 确定控制范围

先确认当前 Blender 版本、目标场景、资产对象或集合，以及以哪套已有运动实现为准。只读取本轮必要依赖；陌生场景可调用[场景盘点](../machine-inspect/SKILL.md)。需要核查 Panel、Operator、属性回调、计时器或上下文行为时，调用[Blender 能力查询](../blender-capabilities/SKILL.md)，依据实际版本选择 API；旧脚本中的写法仍需核查适用性。

按用户要观察的问题设置少量有意义的控制，使用当前资产的对象和布局：

| 控制 | 预期行为 |
| --- | --- |
| 视角 | 按需提供整体、对齐或局部视图；保持手动旋转、缩放和自由查看能力 |
| 显隐 | 对目标外壳、遮挡部件或辅助物临时显隐，保留判断所需的周边参照 |
| 播放、暂停、复位 | 播放接续当前进度；暂停停在当前姿态；复位暂停并回到约定起点 |
| 进度 | 显示正确单位与范围，暂停后可跳到任意有效位置，并同步当前姿态 |

按资产需要取舍控制项。无运动资产只提供查看控制；确需运动但缺少已有实现时，说明缺口，按已授权范围交给[动画](../machine-animate/SKILL.md)处理。

面板适配既有关键帧、驱动器、约束或参数化运动入口，使用同一时间定义与求值路径；不得复制一套近似运动或另建播放器专用的运动逻辑。明确播放期间跳转、终点停止或循环的行为；阶段名称仅在已有运动实现提供时显示。

可以参考已有面板的操作安排，但目标资产的绑定和交互需重新实现。不得携带参考机器的模型、材质、对象名、固定机位或机构专用代码，也不为此次制作扩展通用播放器框架。

## 实现与恢复

将面板脚本保存在目标项目中，沿用已有目录；没有约定时可放在 `scripts/<机器名>/review_panel.py`。路径和依赖从实际项目确定，不依赖技能安装目录、缓存或临时文件。若依赖 Blender 文本块或外部运动脚本，交代其实际名称或路径及加载方式。

为本资产的注册类、属性和运行状态设置稳定且独立的命名空间。安装前检查场景、对象、集合与运动入口。缺少依赖时，说明具体缺失项及修复方向，并先阻止相关控制运行，避免注册不完整或只修改了部分场景状态。安装失败时，清理本次已建立的资源并恢复受影响状态。

脚本只在用户手动运行时安装面板，安装后保持暂停。提供明确的卸载入口；不设置启动文件、自动运行文本、加载处理器或其他自启机制。

再次运行时，先安全结束本面板的旧播放并清理旧实例，再更新注册，避免重复类、回调、计时器或失效引用。卸载和重复卸载均应安全，只移除本面板拥有的资源。场景切换、目标删除、窗口关闭或播放异常后，也应释放自身播放资源并说明原因。

面板首次改变状态前，保存其原始值，包括目标视口的方向、位置、距离、投影，以及将要修改的显隐、着色、叠加等设置。若改变帧、播放范围或其他场景状态，也纳入恢复范围。提供“恢复查看状态”，卸载时恢复这些改动；重复运行时保留最初保存的状态，不用面板已修改的状态覆盖它。

记录关联的场景、视口和对象身份，原目标已不存在时，安全跳过并提示。尽量只操作用户指定的当前视口，不遍历改写所有窗口，不强制切换场景。保留用户自由查看的能力，恢复范围限于面板实际改变的状态。

## 验证与交付

静态检查和后台 Blender 验证可覆盖语法、依赖校验、注册与卸载、运动源调用和状态恢复数据。用户已手动启动面板且交互环境可用时，在实际 Blender 界面中验证本次提供的控制。其他情况下，交付脚本、启动说明及待验证项，不为测试擅自启动用户面板。交互验证包括：

- 从文本编辑器运行后侧栏可见，标签清楚，初始保持暂停；再次运行和连续卸载不留下重复资源。
- 每个视角、显隐组合能揭示预期部位，手动旋转与缩放可用；恢复与卸载能还原保存的原始状态。
- 有运动时验证播放、暂停、继续、复位、进度跳转与终点行为，并与已有运动源的对应姿态一致；播放中重载或卸载能停止自身更新。
- 对相关缺失依赖和失效上下文验证可解释的失败及清理，不影响其他工具或资产。

完成条件是脚本已保存到目标项目、依赖可定位、控制与现有资产和运动源一致，重复运行及卸载可恢复，且结果清楚区分已验证与未验证的部分。后台执行成功不能证明侧栏显示、鼠标交互或连续播放已验证。没有交互环境时，明确列出尚待界面验证的项目；面板就绪不能作为模型通过审阅的依据。

交付脚本的准确绝对路径、目标 `.blend`、依赖位置、侧栏标签和卸载方式。说明手动启动步骤：在目标 Blender 文件中切到“脚本 / Scripting”工作区，在“文本编辑器 / Text Editor”打开交付脚本，点击“运行脚本 / Run Script”（鼠标位于文本编辑器时可按 `Alt-P`），再到 3D 视图按 `N` 打开对应侧栏标签。保存脚本和项目所需依赖后结束；不替用户自动运行或启动 Blender。
