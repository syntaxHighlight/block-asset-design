# 几何检查

按[工具说明](../machine-design/shared/references/tools.md)使用 `blender_audit.py`，或导出 JSON 后运行 `mesh_checks.py`。明确对象范围、源/求值几何、姿态、单位、坐标系和容差。只检查选择的对象；实例需要显式包含。对象、材质或依赖尚不清楚时，按需使用[场景盘点](../machine-inspect/SKILL.md)。

- 破面：退化面、非平面多边形、非流形边、开放边界、相邻面绕序异常分别定位；开放渲染网格不自动当作错误。
- 重叠面：报告有正面积的共面三角交叠，区分同向与反向；工具不执行体积包含、一般非共面碰撞或连续扫掠检测。
- 空间网格：按目标原点、参考态及步长检查；可按对象设置 `md_grid_step` 覆盖默认步长。Minecraft 的接口、主体、细节规则分别见[配置](../machine-design/shared/references/profiles/minecraft.md)。顶点偏离指定网格时不自动吸附，尤其是斜面、八边形和运动中的部件。

报告可能包含候选、未检查或预算截断，不能把截断当作通过。源面索引可直接定位；求值网格/实例索引仅属于该快照。修复由对应制作技能主导，完成后在相同范围复查，必要时扩大关联检查。已有修复授权时可连续完成必要修改；用户只要求检查时，不修改资产。
