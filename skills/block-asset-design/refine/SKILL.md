# 模型修饰

读取[工作约定](../shared/references/workflow.md)和[几何与语义契约](../shared/references/geometry.md)。本技能无需原始生成脚本。改变整体比例、布局或功能构件时，交给[建模](../model/SKILL.md)处理；局部形体调整仍可在本技能中完成。

1. 明确本轮要处理的轮廓、接缝、拓扑、法线、遮挡或实际渲染开销问题。需要选择拓扑操作或不确定工具行为时，使用[Blender 能力查询](../blender-capabilities/SKILL.md)比较相关方法。
2. 确认对象与属性保留范围。保留必要的外观分界和材质分区；需要分别运动、显隐或控制的部件应保持独立。必要时保留来源或恢复点，无需每轮复制整体资产。
3. 先解决实体接合与轮廓，再按实际需要简化。孔洞周围出现细桥或狭长面时允许局部增加面数。隐藏面剔除属于最终渲染优化；剔除后重新检查闭合性，不能再默认满足实体布尔运算的闭合条件。
4. 拓扑变化后检查语义、UV 层及约束/脚本引用；面编号不是持久身份。标记真实形体边与装配缝，UV 切口独立设置。无法确认属性是否正确迁移时，报告情况并重新标记受影响部分。
5. 结合[几何检查](../geometry-check/SKILL.md)、[UV 检查](../uv-check/SKILL.md)及[审阅](../review/SKILL.md)复查受影响范围。对象合并或机构引用变化时还要验证组合运动。

完成条件：本轮修饰目标已达成，必要轮廓、接口、运动关系和受保护表面均已保留，并已说明检查范围。若声称性能改善，需提供实际测量结果，不能只依据减面率。
