# 几何检查

按[工具说明](../shared/references/tools.md)使用 `blender_audit.py`，或导出 JSON 后运行 `mesh_checks.py`。明确对象范围、源/求值几何、姿态、单位、坐标系和容差。检查仅覆盖所选对象，实例需显式包含。对象、材质或依赖尚不清楚时，按需使用[场景盘点](../inspect/SKILL.md)。

- 几何异常候选：分别定位退化面、非平面多边形、面的开放边界、连接超过两个面的边及相邻面绕序异常；开放渲染网格是否有误需另行判断。
- 重叠面：报告面积大于零的共面三角形交叠，区分同向与反向；工具不执行体积包含、一般非共面碰撞或连续扫掠检测。
- 空间网格：按目标原点、参考态及步长检查；可按对象设置 `md_grid_step` 覆盖默认步长。Minecraft 的接口、主体、细节要求见[Minecraft 制作规则](../shared/references/profiles/minecraft.md)。顶点偏离指定网格时不自动吸附，尤其是斜面、八边形和运动中的部件。

区分候选问题、未完成的检查和省略的定位样例。达到计算预算会使相应检查未完成，不能视为通过；仅限制样例数量时，检查总数仍有效，但样例只展示部分候选。结合报告中的状态、总数和预算判断覆盖范围。

源面索引可直接用于定位；求值网格或实例索引仅适用于该快照。修复交给对应制作技能处理，完成后在相同范围复查，必要时扩大关联检查。已有修复授权时可连续完成必要修改；用户只要求检查时，不修改资产。
