# 动画

读取[工作约定](../shared/references/workflow.md)，沿用建模或已有资产中的动画控制器，避免另建临时动画后再重做。可为最终动作重构约束；先查清控制参数、父子关系、驱动器及脚本引用，信息不足时使用[场景盘点](../inspect/SKILL.md)，需要选型时使用[Blender 能力查询](../blender-capabilities/SKILL.md)。

若任务转为重新设计主体布局或功能构件，交给[建模](../model/SKILL.md)处理；运动所需的局部几何调整按相关规则完成。

涉及机械联动、行程或接触时读取[机械设计规则](../shared/references/profiles/mechanical.md)。

1. 先确认动作目标、起止和中间姿态，以及设计允许的接触；再调整速度、停顿及约定的终点行为，需要循环时再处理循环衔接。分别判断运动是否合理、演示节奏是否合适；简化动作不宣称为工程仿真。
2. 预览播放器使用模型现有的动画控制器，不另建一套运动逻辑。验证从任意有效姿态起播、前后跳转、复位和约定的终点行为均无状态漂移；需要循环时验证循环衔接。姿态求值不能依赖上一帧的累积状态。几何发生变形时，同时检查纹素密度与拉伸。
3. 动画控制重构后检查约束目标是否丢失、驱动器和对象引用是否有效，并复查交接位置及受影响的组合动作。区分装饰性静态部件和需要运动的部件，只为需要动作的部分添加动画。
4. 按[审阅](../review/SKILL.md)观察连续动作、关键交接及遮挡；必要时读求值几何进行碰撞检查。机械接触按专项规则判断，分别说明允许的接触与意外穿透。
5. 保留可编辑动画控制；仅目标导出确有需要时烘焙派生动画。导出变形动画时，检查拓扑是否跨帧保持一致；求值网格编号不保证跨帧一致。

完成条件：本轮动作、交接、节奏和约定终点行为符合要求，并有实际观察支持；需要循环时已验证循环衔接，跳转抽查未发现状态漂移。说明采样覆盖范围，以及尚未验证的连续扫掠范围。截图或有限姿态检查通过，不能证明连续运动无碰撞。
