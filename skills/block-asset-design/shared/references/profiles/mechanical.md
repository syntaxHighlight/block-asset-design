# 机械设计规则

制作或修改有机械功能、传动与装配关系的资产时读取；静态道具和装饰按自身用途选择适用项。

- 先核实要表现的功能、接口和占位，再设计外露机构；未定玩法不固化为机械构件。
- 按功能组检查支承、连接、厚度、工作通路和接触关系。部件方向、比例与组合方式应支持其用途；有意简化按设计目标判断，不宣称为工程仿真。
- 建立运动前明确轴心、行程、联动、关键交接姿态与净空。分别检查静态占位和运动包络；普通 Limit 约束不能替代几何碰撞检查。
- 刀具的工作接触、刚性部件的固定接合与意外穿透分别判断。需要连续运动结论时，关键帧或有限采样不能证明整个行程无碰撞。
- 伸缩件以固定基准长度或参考态几何计算变形，并复查纹素密度与拉伸；装饰性紧固件无需单独增加动画。
- 多方块设备按目标项目的连接面与安装基准定位。外壳突出、运动越界是否允许，由用途和游戏接入契约确定。

偏工业低面数造型可采用 1/16 方块的主体网格、1/32 的细节网格及八边形圆截面，但这些是可选风格约定。采用八边形时，明确内切或外接半径、截面朝向和步长；保留比例，不为顶点吸附而改变形态。IE 风格另见 [IE 参考](ie-style.md)。
