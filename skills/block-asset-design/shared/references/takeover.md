# 接手已有资产

模型并非由本技能生成、缺少标记，或中途由用户/其他工具接管时，按以下步骤接手，无需重新走草稿阶段。

1. 复用与当前资产一致的场景记录；信息不足时调用[场景盘点](../../inspect/SKILL.md)，查明对象、材质、UV、约束、驱动器和外部依赖，据此确定制作依据与保护范围。已有信息足够时不重复盘点。
2. 根据现有共识与资产，确认本轮保护范围、观看条件和目标。未知信息保留为未知，只询问会改变本轮选择的事项，无需让用户填写完整问卷。
3. 当前手工模型默认是制作依据。查清生成脚本覆盖范围后才重生成；不能仅凭文件名推定“最新”或因结构不熟悉而重建。
4. 缺少语义时仅补受影响区域，已有材质、顶点组和自定义属性可作为判断依据，但需核实是否仍然有效。拓扑变更后重新验证映射。
5. 根据诊断发现的问题与目标的关系，决定哪些需要处理，并报告有影响而无法验证的依赖。优先局部修改，不自动清理旧文件、重命名全部对象或覆盖整个场景。

完成条件：已确定可操作的资产入口，明确修改与保留范围，能够进入所需阶段。
