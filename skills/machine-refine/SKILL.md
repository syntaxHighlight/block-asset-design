# 模型修饰

读[工作约定](../machine-design/shared/references/workflow.md)和[几何与语义契约](../machine-design/shared/references/geometry.md)。不要求原始生成脚本。改变整体比例、布局或功能构件时，由[建模](../machine-model/SKILL.md)主导；局部形体调整仍可在本技能中完成。

1. 识别本轮问题：轮廓、接缝、拓扑、法线、遮挡或实际渲染开销。需要选择拓扑操作或不确定工具行为时，按[能力查询](../blender-capabilities/SKILL.md)比较相关方法。
2. 确认对象与属性保留范围。保留必要的外观分界和材质分区；需要分别运动、显隐或控制的部件应保持独立。必要时保留来源或恢复点，无需每轮复制整机。
3. 先解决实体接合与轮廓，再按实际需要简化。孔洞周围出现细桥或狭长面时允许局部增加面数。隐藏面剔除属于最终渲染优化；剔除后重新判断闭合性，不继续假定实体布尔前提成立。
4. 拓扑变化后检查语义、UV 层及约束/脚本引用；面编号不是持久身份。标记真实形体边与装配缝，UV 切口独立设置。属性迁移不确定时报告并重标受影响部分。
5. 结合[几何检查](../machine-geometry-check/SKILL.md)、[UV 检查](../machine-uv-check/SKILL.md)及[审阅](../machine-review/SKILL.md)复查受影响范围。对象合并或机构引用变化时还要验证组合运动。

完成条件：目标形态改善，必要轮廓、接口、运动关系和受保护表面保留，说明检查过的范围。若声称性能改善，需提供实际测量结果，不能只依据减面率。
