# ADR 0001：简化分发并移除 SkVM

- 状态：已接受
- 决定日期：2026-11-01
- 确认：用户于 2026-11-01 确认以下分发与维护决定。

## 背景

本仓库分发 `block-asset-design` 技能集合，配套 Python 工具已位于集合目录中，随技能一起安装。目标项目需要一份可按资产与项目约定修改的工具副本。

原有的独立 release 工具下载，让技能安装与工具准备形成两条分发路径，增加版本对应、下载与维护成本。项目还曾在本地维护 SkVM 的能力画像、AOT/JIT 优化、转炉接管试点与语义审阅工具链；它不属于公共技能运行依赖，用户已确认不再需要。

## 决定

1. 保留 `npx skills add` 作为唯一技能安装入口，安装完整 `block-asset-design` 集合。
2. 配套工具随技能安装。首次需要时，`tool-setup` 从已安装的技能目录复制工具到目标项目，在该项目中审阅、适配与验证；后续重复准备保留已有修改。
3. 取消从 release 下载独立工具包的流程，不再为工具维护第二条分发路径。
4. 移除本项目的 SkVM 本地维护工具，包括专用 CLI、支持代码、配置、测试、操作文档、vendor 工作树及专用运行环境；公共技能不依赖 SkVM。
5. 保留本地历史实验记录、冻结资产和证据。保留这些材料用于追溯，不表示项目仍依赖或继续运行 SkVM。

## 取舍与后果

采用随技能携带工具、再复制到项目的方式，技能与初始工具来自同一次安装，也允许目标项目独立适配。代价是项目副本不会自动跟随技能更新；需要升级时，应核对已有修改并在目标项目验证。

相比继续维护独立 release 下载，统一入口减少安装步骤和版本对应关系。项目不再提供单独下载工具包的安装方式。

相比保留 SkVM 工具链，移除它减少本地运行时、兼容补丁和评测维护成本。现有历史记录继续保留，但已不能通过本仓库中的旧入口直接重跑；未来若重新引入类似能力，应另行决定其范围和验证方式。
